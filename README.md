# Herdr Remote — 安裝檔下載

用 iPhone 看和操作電腦上 [herdr](https://herdr.dev) 裡的 AI agent（Claude Code、Codex），只走你自己的 Tailscale 網路。

這裡只放安裝檔。下載最新版：<https://github.com/aeronan/herdr-remote-releases/releases/latest/download/herdr-remote.zip>（Mac 和 Windows 共用），解壓縮後照裡面的 `README.txt` 安裝：

- **Mac**：打開「終端機」，輸入 `sh `，把 `Install-Mac.command` 拖進視窗，按 Enter。
- **Windows**：解壓縮後雙擊 `Install-Windows.cmd`。

需要先裝好：Tailscale（電腦和 iPhone 同一個帳號）、Node.js 20 以上、herdr。
